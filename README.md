# Java Projects / Java 项目

这里汇总了 Java 数据结构与控制台应用项目。完整的音频播放列表管理器和 RFID 库存管理器位于 `homework` 分支，提供中英文双语说明与编译运行步骤。

This repository hosts Java data-structure and console application projects. The complete Audio Playlist Manager and RFID Inventory Manager are on the `homework` branch, with bilingual descriptions and build instructions.

这些交互式应用展示定长数组和自定义双向链表的实现，覆盖有序插入、位置更新、深拷贝、遍历、结账流程与节点删除。程序使用 Java 标准库，状态保存在内存中。

These interactive applications demonstrate a fixed-capacity array and a custom doubly linked list, including ordered insertion, positional updates, deep copying, traversal, checkout, and node removal. They use the Java standard library and keep state in memory.
